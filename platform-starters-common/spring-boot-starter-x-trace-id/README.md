# Custom Trace ID Spring Boot Starter

Эта библиотека предоставляет простой механизм для передачи пользовательского идентификатора трассировки (`TraceID`) через HTTP-заголовок `x-trace-id`, устраняя необходимость формировать полный W3C `traceparent`.

Решение предназначено для улучшения UX при интеграции сервисов и поиске запросов в Grafana, позволяя клиентам использовать заранее известный идентификатор для корреляции.

## Подключение библиотеки:

1. Указать репозитории зависимостей:
```groovy
repositories {
    maven {
        url = "https://n.1440.space/repository/platform-maven/"
    }
    maven {
        url = "https://n.1440.space/repository/platform-maven-dev/"
    }
}
```
2. Указать зависимость.
```groovy
dependencies {
    implementation 'space.br1440.platform.starters:spring-boot-starter-x-trace-id:{Желаемая версия}'
}
```

## Что делает библиотека
-	читает входящий заголовок x-trace-id;
-	валидирует его;
-	использует его как TraceID, если отсутствует валидный traceparent;
-	возвращает фактический TraceID текущего запроса в response header x-trace-id;
-	не ломает запрос, если x-trace-id невалиден: пишет warning и продолжает работу в штатном режиме.

## Правила валидации x-trace-id

x-trace-id считается валидным, если:
1.	содержит ровно 32 hex-символа ([0-9a-fA-F]);
2.	не состоит только из нулей.

## Приоритет заголовков (Tracing Context)

При построении контекста трассировки применяется следующая логика:

1. **`traceparent` (наивысший приоритет):** Если передан валидный стандартный W3C `traceparent`, он используется как источник истины. Заголовок `x-trace-id` в этом случае игнорируется.
2. **`x-trace-id` (альтернативный):** Если `traceparent` отсутствует, но передан валидный `x-trace-id`, он становится идентификатором текущего трейса.
3. **Fallback (новый trace):** Если `traceparent` отсутствует, а `x-trace-id` отсутствует или невалиден (записывается лог), генерируется новый стандартный TraceID.

Во всех случаях в HTTP-ответе сервис вернет заголовок `x-trace-id` с итоговым идентификатором.
